## ⭐ 1. ProgressHub — Productivity & Goal Management Platform

<p>
  <img src="https://img.shields.io/badge/Java-8B5E3C?style=flat-square&logo=openjdk&logoColor=white" />
  <img src="https://img.shields.io/badge/Spring_Boot-8B5E3C?style=flat-square&logo=springboot&logoColor=white" />
  <img src="https://img.shields.io/badge/React-8B5E3C?style=flat-square&logo=react&logoColor=white" />
  <img src="https://img.shields.io/badge/PostgreSQL-8B5E3C?style=flat-square&logo=postgresql&logoColor=white" />
  <img src="https://img.shields.io/badge/JWT-8B5E3C?style=flat-square" />
</p>

A full-stack productivity platform designed to help users build consistent habits, manage daily tasks, track progress, and turn bigger goals into achievable steps.

### ✨ Key Features

- 🔐 Secure authentication using JWT and Google OAuth.
- 🎯 Habit creation and daily habit tracking.
- 📅 Daily task management and planning.
- 📊 Analytics dashboard to visualize productivity and consistency.
- 🔗 Google Calendar integration.
- 🤖 Steppie AI — personalized goal roadmaps broken into manageable weekly steps (in development).

### ⚙️ Technical Highlights

- RESTful API development using Spring Boot.
- PostgreSQL database integration with Spring Data JPA.
- Authentication and authorization.
- React frontend and backend integration.
- AI integration for roadmap generation.
